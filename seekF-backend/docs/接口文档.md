# seekF-backend 接口文档

本文档根据当前代码（`internal/router/router.go`、`internal/controllers/user/*`、`internal/dto/user/*`、`internal/services/user_service/*`）整理。

## 基础信息

- **服务端口**：代码 `main.go` 使用 `r.Run()`，Gin 默认监听 `:8080`（若你在其他地方通过环境变量/参数覆盖端口，请以实际运行配置为准）
- **统一前缀**：`/user`
- **请求方式**：目前接口均为 `POST`
- **Content-Type**：`application/json`

## 鉴权说明（Token）

除 `register/login` 外，其余接口都需要在请求头带上：

- **Header**：`Authorization: Bearer <token>`
- **token 来源**：登录接口 `/user/login` 的响应字段 `data.token`

后端支持两种认证方案，通过 `config/config.toml` 的 `authConfig.mode` 切换：

- **`redis`（默认）**：不透明 token + Redis 会话（推荐）
- **`jwt`**：纯 JWT（无服务端状态；登出由客户端丢弃 token）

## 通用响应结构

后端统一返回 HTTP 200，但通过 JSON 字段 `code` 表示业务状态：

- **成功**：

```json
{
  "code": 200,
  "message": "xxx",
  "data": {}
}
```

- **失败**（通常 `code` 为 400/401/403/500 等，且一般没有 `data`）：

```json
{
  "code": 400,
  "message": "错误原因"
}
```

## 接口总览

| 模块 | 鉴权 | 方法 | Path |
| --- | --- | --- | --- |
| 用户 | 否 | POST | `/user/register` |
| 用户 | 否 | POST | `/user/login` |
| 用户 | 是 | POST | `/user/logout` |
| 用户信息 | 是 | POST | `/user/userinfo/getUserinfo` |
| 用户信息 | 是 | POST | `/user/userinfo/updateUserInfo` |

## 1. 用户注册

- **方法**：POST
- **Path**：`/user/register`
- **鉴权**：否

### Request Body（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `nickname` | string | 是 | 昵称 |
| `telephone` | string | 是 | 手机号 |
| `password` | string | 是 | 密码 |

示例：

```json
{
  "nickname": "张三",
  "telephone": "13800000000",
  "password": "123456"
}
```

### Response

成功示例：

```json
{
  "code": 200,
  "message": "注册成功"
}
```

---

## 2. 用户登录

- **方法**：POST
- **Path**：`/user/login`
- **鉴权**：否

### Request Body（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `telephone` | string | 是 | 手机号 |
| `password` | string | 是 | 密码 |

示例：

```json
{
  "telephone": "13800000000",
  "password": "123456"
}
```

### Response（data）

`data` 结构：

```json
{
  "user": {
    "uuid": "Uxxxxxxxxxxx",
    "telephone": "13800000000",
    "nickname": "张三",
    "email": "",
    "avatar": "",
    "gender": 0,
    "birthday": "",
    "signature": "",
    "isAdmin": 0,
    "status": 0
  },
  "token": "eyJhbGciOi..."
}
```

完整成功示例：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "user": {
      "uuid": "Uxxxxxxxxxxx",
      "telephone": "13800000000",
      "nickname": "张三",
      "email": "",
      "avatar": "",
      "gender": 0,
      "birthday": "",
      "signature": "",
      "isAdmin": 0,
      "status": 0
    },
    "token": "eyJhbGciOi..."
  }
}
```

## 3. 用户登出

- **方法**：POST
- **Path**：`/user/logout`
- **鉴权**：是（`Authorization: Bearer <token>`）

### Request Body（JSON）

无（可传空对象 `{}`）。

### Response

成功示例：

```json
{
  "code": 200,
  "message": "退出登录成功"
}
```

- **方法**：POST
- **Path**：`/user/userinfo/getUserinfo`
- **鉴权**：是

### Request Body（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `uuid` | string | 否 | 用户 UUID（当前实现未强制 required） |

示例：

```json
{
  "uuid": "Uxxxxxxxxxxx"
}
```

### Response（data）

```json
{
  "uuid": "Uxxxxxxxxxxx",
  "nickname": "张三",
  "telephone": "13800000000",
  "avatar": "",
  "email": "",
  "gender": 0,
  "birthday": "",
  "signature": "",
  "created_at": "2026-03-12 10:00:00",
  "is_admin": 0,
  "status": 0
}
```

## 5. 更新用户信息

- **方法**：POST
- **Path**：`/user/userinfo/updateUserInfo`
- **鉴权**：是
- **权限限制**：只能更新自己的信息（`req.uuid` 必须等于 token 内的 `Uuid`）

### Request Body（JSON）

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `uuid` | string | 否 | 用户 UUID（当前实现未强制 required，但会用于“只能更新自己”校验） |
| `email` | string | 否 | 邮箱 |
| `nickname` | string | 否 | 昵称 |
| `birthday` | string | 否 | 生日（字符串） |
| `signature` | string | 否 | 个性签名 |
| `avatar` | string | 否 | 头像 URL |

示例：

```json
{
  "uuid": "Uxxxxxxxxxxx",
  "nickname": "新昵称",
  "avatar": "https://example.com/a.png"
}
```

### Response

成功示例：

```json
{
  "code": 200,
  "message": "更新用户信息成功"
}
```
